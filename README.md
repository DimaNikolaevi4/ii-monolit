# ИИ-Монолит

Российская большая языковая модель 7B для практических задач: генерация, анализ и развёртывание в контуре заказчика.

**Сайт:** https://ии-монолит.рф/

## Что в репозитории

| Путь | Что это |
|------|---------|
| `index.html` | **Актуальная версия сайта** — снимок с прода от 17.11.2026 («ИИ-Монолит · Большая языковая модель 7B»). Один самодостаточный файл: стили и скрипты внутри, внешних зависимостей нет |
| `archive/2026/` | Прежняя многостраничная версия: главная «ИИ под ключ — от данных до прода», датасеты, развёртывание, дообучение, портфолио, правовая информация + `css/`, `js/`, `img/` |
| `plan.json` | Задачи репозитория для общего календаря (сейчас — заглушка «срочных дел нет») |
| `products/ai-tutor/` | **Код продукта** — ИИ-тьютор для СПО: Python-сервис (`tutor.py`, `train.py`, `evaluate.py`), API, плагин Moodle, датасеты, Docker (`Dockerfile`, `docker-compose.yml`), 92 документа. Перенесён из отдельного репозитория `al` вместе с историей (152 коммита) |

## Задачи

Задачи уровня репозитория держим здесь, в календарь они не выводятся.

- **Переход на свою модель.** Продукт линейки — ИИ-тьютор для СПО (репозиторий `al`) — сейчас работает на Mistral Small 24B. Планируется перевод на ИИ-Монолит 7B: это и импортозамещение, и обкатка модели на реальной нагрузке.
- **Синхронность с продом.** `index.html` в репозитории должен совпадать с тем, что открывается на сайте. Любая правка на хостинге — сразу снимок в репозиторий, иначе версии снова разойдутся (так уже было: осенью репозиторий и прод отличались).

## Технологии

Сайт (корень репозитория) собирается как статика; продукт в `products/ai-tutor/` — отдельный Python-проект:
сборка и запуск выполняются из этой папки (`docker compose up` / `make`), пути в `Dockerfile` и `docker-compose.yml`
рассчитаны на её корень.


- Актуальная версия: HTML5, CSS и JavaScript без внешних библиотек — один файл, работает автономно
- Архив 2026: Bootstrap 5.3, Bootstrap Icons 1.11, GSAP 3.12.5, шрифт Geist (через CDN)

> В архивных страницах пути абсолютные (`/css/…`, `/js/…`), поэтому из подпапки они не открываются напрямую — подробности в `archive/2026/README.md`.
