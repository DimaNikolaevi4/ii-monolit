# ИИ-Монолит

**Живой сайт: [https://ии-монолит.рф/](https://ии-монолит.рф/)** — российская большая языковая модель 7B.

В репозитории лежит **актуальная версия сайта** (снимок прода от 17.11.2026) и архив прежней многостраничной версии.

## Структура

| Путь | Что это |
|------|---------|
| `index.html` | **Прод-версия** сайта: «ИИ-Монолит · Большая языковая модель 7B» — один самодостаточный файл (CSS/JS внутри, внешних зависимостей нет), 38,6 КБ |
| `archive/2026/` | Прежняя многостраничная версия «ИИ-Монолит — Разработка ИИ-решений / ИИ под ключ»: `index`, `datasets`, `deployment`, `finetuning`, `portfolio`, `legal` + `css/`, `js/`, `img/` |
| `.replit` | Конфигурация Replit-окружения |
| `plan.json` | Задачи репозитория для общего календаря |

> ⚠️ В архивных HTML пути абсолютные (`/css/…`, `/js/…`, `/img/…`), поэтому из подпапки они не открываются «как есть» — это нормально для архива: чтобы посмотреть, скопируйте содержимое `archive/2026/` в корень любого статического сервера.
