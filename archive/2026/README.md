# Архив прежней версии сайта (до 17.11.2026)

Многостраничная версия «ИИ-Монолит — Разработка ИИ-решений / ИИ под ключ — от данных до прода».

- `index.html` — главная: «ИИ под ключ — от данных до прода»
- `datasets.html` — создание датасетов
- `deployment.html` — развёртывание моделей
- `finetuning.html` — дообучение ИИ
- `portfolio.html` — портфолио и экспертиза
- `legal.html` — правовая информация
- `css/`, `js/`, `img/` — стили, скрипты, картинки; в корне — логотипы и фавиконы

**Важно:** в HTML пути абсолютные (`/css/…`, `/js/…`, `/img/…`), поэтому страницы не открываются из подпапки напрямую. Для просмотра скопируйте содержимое этой папки в корень статического сервера (или поднимите локальный сервер с этой папкой как корнем).

Актуальная версия сайта — в корне репозитория (`index.html`, снимок прода от 17.11.2026).
